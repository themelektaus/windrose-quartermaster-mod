Talent Points

Multiplier on every level's talent reward. Some vanilla level-ups grant 0-1 talent points; boosting ADDS the multiplier there instead of scaling (at 3x: 0→3, 1→4), while richer levels scale (2→6, 3→9). Per-level overrides win.

1x

Stat Points

Hybrid multiplier on every level's stat reward. Per-level overrides win.

1x

1x = vanilla. A number box pins an exact reward for that level; leave it blank to follow the multiplier above. The level-1 starting row is fixed at vanilla.

Per-level rewards

Each row is one level-up of the reward table (DA_HeroLevels). The number boxes set an exact talent / stat reward for that level (winning over the multiplier); leave a box blank to follow the multiplier. The XP curve itself is unchanged, and points already earned stay baked into existing saves - this only affects level-ups after install.
