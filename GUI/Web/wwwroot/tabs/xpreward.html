Quest XP

Base multiplier on every quest reward (faction / main / side / local-event) whose own row is at 1x. Per-quest overrides win.

POI Chest XP

Base multiplier on every POI treasure-chest reward whose own row is at 1x. Per-chest overrides win.

1.0x

Vanilla = 1.0x. Range 0.1x - 10x. A row at 1x follows its overall; any other value pins that entry.

Per-entry XP overrides

Each row scales one quest's or chest's ExperienceCount. A slider at 1x follows the matching overall above; any other value pins that entry to its own scale. Entries with no vanilla XP are not listed.
