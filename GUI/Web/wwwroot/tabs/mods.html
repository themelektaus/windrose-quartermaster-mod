Game install

Steam installs are auto-detected. For Epic / GOG / dedicated server / portable copies, set the path to your Windrose folder (the one that contains R5\Binaries\Win64\Windrose-Win64-Shipping.exe, or WindroseServer-Win64-Shipping.exe on a dedicated server) - all build / deploy / play paths derive from it.

Export as ZIP

Download all deployed Quartermaster files (paks, DLL, sidecars) as a single ZIP. Extract into any Windrose install folder (client or dedicated server).

Setup

Re-open the first-run setup dialog to re-dump vanilla item JSONs or re-extract icon textures - useful after a game update.

Dedicated server

When a R5\Builds\WindowsServer\ folder exists next to the game install, builds are automatically deployed to both client and server.

Export building assets

Extracts every building asset (DataAssets, Blueprints, Static Meshes, Materials, Textures, audio cues) from the vanilla IoStore container to Sources/Vanilla/R5/Content/ so you can clone them in the UE editor.

Heads up: writes several hundred MB to disk and takes 1-3 minutes the first time. Re-running is incremental - existing files are kept.
