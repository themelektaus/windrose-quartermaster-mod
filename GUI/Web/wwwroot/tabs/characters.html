Save Patcher

Retro-fits onto your EXISTING characters what the paks only grant to newly created ones: ring / necklace slots, each ship's cargo / combat orders, and the Level Rewards talent / stat points. The sliders on the Basic / Level Rewards tabs drive the target.

One card per character. When anything differs from the profile the "Backup + patch" button activates and writes only what's needed; a backup is made automatically first.

Level Rewards points follow the multiplier both ways: lowering it (e.g. back to 1x) reduces the free pool toward vanilla. Only unspent points change - already-invested points are kept.

Close Windrose completely and turn OFF Steam Cloud Sync for Windrose first, or the cloud will overwrite the patched save on next launch.
