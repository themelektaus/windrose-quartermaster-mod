Character Slot Patcher

Retro-fits ring / necklace slot counts onto your EXISTING characters. The Equipment Slots sliders on the Basic tab only affect newly created characters - this writes the matching slot count straight into each character's save.

Each character is compared against the profile's slider target. A "Patch" button only appears when they differ; before writing, a per-character backup is created automatically.

Close Windrose completely and turn OFF Steam Cloud Sync for Windrose first, or the cloud will overwrite the patched save on next launch.
