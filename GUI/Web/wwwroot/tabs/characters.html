Save Patcher

Retro-fits slot counts onto your EXISTING characters and ships. The Equipment Slots and Ship Slots sliders on the Basic tab only affect newly created characters / ships - this writes the matching counts straight into the save.

Each row is compared against the profile's slider target. A "Patch" button only appears when they differ; before writing, a per-target backup is created automatically.

Close Windrose completely and turn OFF Steam Cloud Sync for Windrose first, or the cloud will overwrite the patched save on next launch.
