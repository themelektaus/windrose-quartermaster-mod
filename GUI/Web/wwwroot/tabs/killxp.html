Default XP per kill

Flat XP granted for any enemy that has no per-enemy value below. 0 = off (vanilla, no XP on kill). Mirrors the Basic tab card.

off

Grants real, persistent XP on every enemy kill through the game's own level-up logic (needs the Quartermaster DLL - deployed automatically on Build). Per-enemy values below override the default; an empty row follows the default.

Per-enemy XP

One row per vanilla enemy type, generated from the game pak. Set a flat XP amount for a type, or leave it empty to follow the default. A broader keyword (e.g. "Mob_Boar") also covers its variants through substring matching; a more specific row wins.
