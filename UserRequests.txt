banditodude:
[x] I did a bit of googling and using the AI mode it suggested trying to copy the mod files into the server directory as well, and that fixed the issue! Maybe this could be mentioned for others trying to use the coop multiplayer mode, since the standard install location is not enough. To get this working, find windrose in your game list. Right click and select Manage > Browse Local Files.
Now you will need to copy the mod files from the standard install location into the WindowsServer folder. This will allow the mods to function in self hosted multiplayer games. 
[x] Another nice option would be a prepackaged zip with the folder structure defined from the Windrose root.
